# AI Football VAR Gesture Recognition Model

A real-time computer vision system built using Python, OpenCV, and MediaPipe to detect and classify football referee VAR (Video Assistant Referee) screen-review hand gestures.

## Tech Stack
* **Python**
* **OpenCV** (Video capture & UI rendering)
* **MediaPipe Hands** (Machine learning spatial landmark tracking)
